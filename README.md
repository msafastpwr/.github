# `.github` — Microsoft Student Ambassadors (FAST-NUCES Peshawar)

This repository serves as the central configuration and community health repository for the **[`msafastpwr`](https://github.com/msafastpwr)** GitHub organization.

---

## 📌 Repository Purpose

GitHub provides organization-wide default community health files. Any repository within the `msafastpwr` organization that does not specify its own community files will automatically inherit the templates, guidelines, and policies defined here.

Additionally, the [`profile/`](profile/) directory houses the public profile README and assets rendered on the organization's landing page at [github.com/msafastpwr](https://github.com/msafastpwr).

---

## 📂 Repository Structure

```
.github/
├── profile/
│   ├── README.md                 # Public landing page README for the msafastpwr organization
│   └── Banner_MSA.jpeg           # Official chapter header banner artwork
├── .github/
│   ├── ISSUE_TEMPLATE/
│   │   ├── bug_report.yml        # Standard bug report template
│   │   ├── feature_request.yml   # Feature / enhancement proposal template
│   │   ├── workshop_request.yml  # Workshop / tech session topic request template
│   │   └── config.yml            # Issue helper configuration and community support links
│   └── PULL_REQUEST_TEMPLATE.md  # Organization-wide Pull Request template
├── CODE_OF_CONDUCT.md            # Community Code of Conduct
├── CONTRIBUTING.md               # Organization-wide contribution guidelines & standards
├── SECURITY.md                   # Security policy & responsible disclosure guidelines
├── SUPPORT.md                    # Support channels and contact information
├── LICENSE                       # MIT License
└── README.md                     # Documentation for this repository (you are here)
```

---

## ⚙️ Maintenance & Governance

- Changes to the organization profile (`profile/README.md`) or community templates must be submitted via a Pull Request.
- All contributions are governed by our [Code of Conduct](CODE_OF_CONDUCT.md) and [Contributing Guidelines](CONTRIBUTING.md).
- To report security vulnerabilities or credential leaks across any chapter repository, refer to [SECURITY.md](SECURITY.md).
