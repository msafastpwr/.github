## 🛠️ Phase 1: Accounts, Tooling & Access (Days 1–3)

Before writing a single line of code or designing a poster, ensure all digital credentials and accounts are configured:

### 1. GitHub Organization Invitation
- You should receive an invitation to join the official **[`msafastpwr`](https://github.com/msafastpwr)** GitHub organization.
- **Action:** Accept the invitation at [github.com/msafastpwr](https://github.com/msafastpwr).
- Set your organization membership visibility to **Public** so that your affiliation is visible on your personal GitHub profile.
- Enable **Two-Factor Authentication (2FA)** on your GitHub account. 2FA is strictly enforced across our organization.

### 2. Communication Channels
- **WhatsApp Core Group:** Our hub for high-priority operational announcements, meeting links, and rapid coordination. (Ensure notifications are on).
- **Discord Server:** Asynchronous technical discussion, peer review, code debugging, and study jams.
- **Official Society Email:** All formal external inquiries must be routed through `msp.pwr@nu.edu.pk`.

### 3. Read Core Governance & Policies
- Take 20 minutes to read:
  - [Code of Conduct](CODE_OF_CONDUCT.md)
  - [Chapter Governance & Constitution](GOVERNANCE.md)
  - [Contributing Guidelines](CONTRIBUTING.md)
  - [Brand Guidelines](BRAND_GUIDELINES.md)

## ☁️ Phase 2: Microsoft Developer Ecosystem Setup (Week 1)

As an MSA ambassador and core team member, you have access to industry-grade developer resources:

### 1. Microsoft Learn Profile Setup
- Create or link your Microsoft account at [Microsoft Learn](https://learn.microsoft.com/).
- Set up your public username and link your profile to track completed modules, trophies, and learning paths.
- Bookmark the official Microsoft Student Hub for curriculum, sandboxes, and certification discounts.

### 2. Activate Microsoft Azure for Students
- Every enrolled university student is eligible for **\$100 in free Azure credits + free developer services** (without requiring a credit card).
- Visit: [azure.microsoft.com/free/students/](https://azure.microsoft.com/free/students/)
- Authenticate using your official university email (`pXX-XXXX@nu.edu.pk`).
- Key services to explore: Azure App Service, Azure Functions, Azure Blob Storage, Azure OpenAI, and Azure SQL.

### 3. Claim the GitHub Student Developer Pack
- Access industry tools including GitHub Pro, free domains, JetBrains licenses, and cloud credits.
- Apply at [education.github.com/pack](https://education.github.com/pack) with your university student ID card or email.

### 4. Standard Local Development Environment
- **IDE:** Visual Studio Code (VS Code) with recommended extensions:
  - *Prettier — Code Formatter*
  - *ESLint*
  - *Live Server*
  - *GitHub Pull Requests and Issues*
  - *Azure Tools Pack*
- **Terminal & Shell:** Git Bash, WSL2 (Ubuntu), or modern PowerShell.
- Configure your Git identity globally:
  ```bash
  git config --global user.name "Your Full Name"
  git config --global user.email "your.nu.student.email@nu.edu.pk"
  ```

## 🎯 Phase 3: Department-Specific Onboarding (Weeks 2–3)

Read the specific section below for the department you were inducted into:

### 💻 1. Technical Team Track
- **Lead / Co-Lead:** Waleeja Khan & Mohsin Ali
- **Your Tasks:**
  1. Clone [`msafastpwr.github.io`](https://github.com/msafastpwr/msafastpwr.github.io) locally.
  2. Read `docs/TASKS.md` and `docs/CONTRIBUTING.md` in that repository.
  3. Run the local preview using VS Code Live Server or `python3 -m http.server 5500`.
  4. Understand our **Dual-Lead Review Policy**: Never merge code directly into `main`. Always open a branch (`feat/<your-name>-<feature>`) and request reviews from both leads.
  5. Familiarize yourself with our standard tech stack: Semantic HTML5, CSS custom properties (`theme.css`), and Vanilla JavaScript modules.

### 👩‍💻 2. Her Tech Wing Track
- **Director:** VP Asawir binte Asif
- **Your Tasks:**
  1. Join the dedicated Her Tech Wing planning circle.
  2. Review the semester roadmap for female developer study circles, competitive programming cohorts, and Azure cloud labs.
  3. Pair up with a junior female undergraduate for 1-on-1 peer onboarding and GitHub profile setup.
  4. Assist in planning the semester's flagship female tech panel and workshop.

### 📸 3. Media Team Track
- **Your Tasks:**
  1. Review our Google Drive / Cloud media storage structure and access rights.
  2. Familiarize yourself with the camera equipment, lenses, gimbals, and audio lapels owned or rented by the chapter.
  3. Understand our post-event media turnaround SLA:
     - Raw photo dump within **12 hours** of event conclusion.
     - Selected, color-graded photos for social media within **24 hours**.
     - Short video recap reel (9:16 vertical) within **48 hours**.

### 🎪 4. Events Team Track
- **Your Tasks:**
  1. Read the [Event Management SOP](EVENT_MANAGEMENT_SOP.md) thoroughly.
  2. Learn the campus administration approval process for reserving Computer Labs (CS-1, CS-2, Main Lab) and the Campus Auditorium.
  3. Master the hardware checklist: Testing the HDMI/VGA projector, audio amplifier, wireless mics, and internet fallbacks 45 minutes prior to every event.

### 📢 5. Outreach Team Track
- **Your Tasks:**
  1. Learn our institutional voice and etiquette when approaching professors, student societies, and guest speakers.
  2. Review the approved email templates in [`COMMUNICATION_POLICY.md`](COMMUNICATION_POLICY.md).
  3. Coordinate classroom announcement schedules (targeting 1st, 2nd, and 3rd-year CS, SE, AI, and Data Science sections).

### 🎨 6. Graphics Team Track
- **Your Tasks:**
  1. Read [`BRAND_GUIDELINES.md`](BRAND_GUIDELINES.md) to internalize official brand colors (Microsoft Blue `#0078D4`, Orange `#F25022`, Green `#7FBA00`, Yellow `#FFB900`).
  2. Request access to the shared Canva / Figma workspace and typography assets (Segoe UI / Inter).
  3. Always submit drafts to the Graphics Lead for review at least 48 hours before planned social media dispatch.

## 🏆 Phase 4: Month 1 Milestone & Probation Review (Week 4)

Every new member completes a 30-day introductory milestone:
- **For Tech Members:** Successfully author, review, and merge at least one pull request to a chapter repository adhering to our git conventions.
- **For Creative / Media Members:** Produce at least two approved graphical assets or media recaps adhering to brand standards.
- **For Events & Outreach:** Actively execute at least one on-campus workshop or complete a corporate outreach/speaker liaison assignment.

Upon completing your first 30 days:
1. You have a formal 1-on-1 check-in with your Department Lead and the Vice President.
2. Your probationary status transitions into full **Core Ambassador Standing**.
3. You are assigned ownership of an upcoming semester deliverable.

## 📜 Ambassador Rights, Privileges & Expectations

### Your Rights & Privileges:
- Official affiliation with Microsoft Student Ambassadors FAST-NUCES Peshawar.
- Right to lead workshops, publish articles, and speak at chapter events.
- Access to exclusive Microsoft Learn vouchers, Azure credits, and certification exam discounts (subject to availability and activity).
- Professional letter of recommendation and verified **Certificate of Service** upon completion of full academic tenure.
- Priority mentorship from alumni working at top global tech firms.

### Your Responsibilities:
- **Reliability:** When you commit to a deadline, deliver on time. If a university exam or emergency arises, inform your lead at least 24 hours in advance.
- **Continuous Learning:** Actively work on your technical skills. We expect every ambassador to complete at least one Microsoft Learn certification path or major cloud project during their tenure.
- **Constructive Communication:** Critique ideas, not people. Elevate your teammates and celebrate their wins.
